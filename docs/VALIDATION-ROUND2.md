## 本轮解决的路径

1. 网络切换、链路变化和系统阻断时隔离缓存、旧响应和旧 DoH 退避状态；上游绑定到系统为辟尘选择的非 VPN 默认网络。不重建 TUN，也不反复执行 Root 暂停恢复。
2. 断网期间保持本地拦截；非命中请求返回 SERVFAIL，避免继续堆积上游查询。收到可用网络回调后恢复查询路径。
3. 订阅下载移出配置锁；下载期间修改名单或档位时，最终提交校验会拒绝过期批次，保留当前配置。后台与手动更新不会并行重复下载。
4. 本地且非模块导入的快照，在来源未变时只记录检查时间，不替换回滚快照。模块模式没有宣称相同的免写优化。
5. 记录追加、清空、开关使用同一进程内锁，避免已清空旧记录被并发追加写回。首页、设置及诊断显示网络状态；连接状态不等于 DNS 可达。

完整实现说明及官方文档依据见 [网络恢复说明](NETWORK-RECOVERY-2026-09-13.md)。
