# 辟尘：本轮改进与验收（未发布源码）

基线：`ec92aca03b3ad053ac2f2752ad9dff697635b4b2`，0.3.0-beta.1。
本文件描述当前开发分支的变化，不表示 `downloads/` 内旧 APK 已获得这些功能。

## 已写入代码

### 1. 可选 DNS CNAME 别名链检查

规则页新增“检查 CNAME 别名链”，默认关闭，仅作用于应用保护（DNS VPN）。
检查与原查询名相连的 IN/CNAME Answer 链，命中当前精确域名黑名单或订阅后返回 NXDOMAIN。
同时检查新上游响应和已有缓存，关闭功能不改变旧路径；未命中的正常 DNS 响应保持原样。

查询名的显式白名单豁免该查询的整条链；目标白名单只豁免那个目标，不隐式豁免后续目标。
与当前查询无关的 Answer、Authority 或 Additional 记录不会造成拦截。
响应完整性、压缩指针、大小写、重复别名、冲突目标、循环、深度上限均有测试。
循环和格式错误属于解析失败，不算广告拦截；合成回复不携带 AD 认证标记。
最多收集 256 个不同 CNAME owner，最多沿查询链走 32 跳，不额外发出网络请求。

边界：不实现 URL/页面内容过滤，不将 DNAME、HTTPS/SVCB 当 CNAME，不主动查询上游省略的链；
不拦截应用自带 DoH/DoT、直连 IP 或未进入本地虚拟 DNS 的流量。此功能不能应用于静态 hosts 模块。

### 2. 一次应用的规则档位

| 档位 | AdAway | 秋风纯广告 | 隐私跟踪 | HaGeZi Light |
| --- | --- | --- | --- | --- |
| 轻量 | 关 | 开 | 关 | 关 |
| 均衡 | 开 | 开 | 关 | 关 |
| 加强 | 开 | 开 | 关 | 开 |

档位名称由实际四个开关推导；用户手动改为其他组合时显示“自定义”。
切换前有确认：保留手动黑白名单，不改应用放行名单；隐私跟踪源关闭，可自行再次开启。
使用现有单事务 `import-settings`，不是依次提交四次来源开关；成功后可一次回滚整个档位。
有 Root 模块时先同步权威配置，再提交；没有 Root 模块时使用本地事务。
模块暂停/应用保护状态不应因档位切换被意外恢复为全局 hosts；宿主测试覆盖这一点。
若还有其他程序同时直接修改模块配置，仍应避免同时操作；该入口不是跨进程配置合并工具。

### 3. 误拦原因可查看

活动页区分普通拦截和“别名拦截”，记录原始查询与实际命中的目标域名。
可搜索查询名或目标名；点开后可检查目标命中来源，并明确解释白名单影响范围。
沿用默认关闭、本机保存、最多 100 条的现有日志边界，不新增日志上传，也不猜测应用归属。

## 自动化验证入口

```sh
# JDK 即可，完全不需要 Android SDK，也不需要 Root。
python3 tools/test_java.py --protocol-only
# 宿主隔离测试，模拟挂载，不触碰真实 /system 或 /data/adb。
python3 -m unittest discover -s tests -p '*test.py' -v
# Android SDK 35 环境中另外进行完整编译与规则解析测试。
python3 tools/package.py --build-app
python3 tools/test_java.py
python3 tools/verify_downloads.py
```

本地协议测试：208 条断言；100,000 个畸形 IP/DNS 包、25,000 个畸形缓存响应、
25,000 个畸形别名响应。它们是固定种子的生成测试，不代表 150,000 台设备或真实广告效果。
模块套件新增档位整批导入、名单保留、暂停保持与一步回滚用例，总计 18 个测试。
完整 Android 编译与 CI 以对应 workflow run 的实际结果为准。

## 交付边界

不改动已发布 APK，不伪造“已覆盖升级”；本轮代码保留基线版本号，属于未发布改进。
正式打包时必须统一提升 App/module/build 的版本号，并使用原签名：
`35ce73c392ad7dd94a1e0c60dd4d89958d4e878cef7f865ceb2e3f91b26cab46`。
随机生成的新签名只能用于隔离构建，不能作为现有用户的覆盖升级包。
模块文件本轮没有变化，内置 ZIP 与独立 ZIP 应保持字节一致。

未完成的真机验收：Magisk/KernelSU/ReSukiSU/APatch 刷写、Android 16/HyperOS，
Wi-Fi/移动网络切换、休眠恢复、应用分身、多个 VPN 冲突与实际 App 广告/登录/支付回归。
不把宿主或 CI 通过写成这些场景通过。下一阶段还需按单独引擎评估开屏控件、内容过滤、
